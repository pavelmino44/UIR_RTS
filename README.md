# УИР РТС — Практические работы

Репозиторий содержит исходный код и материалы для практических работ по дисциплине **«Управление интеллектуальными роботами и робототехническими системами»**.

* Корнев К. А.
* Мино П. С.
* Ярошенко А. В.

## 📂 Структура проекта

* `Practice_1/` — Поиск экстремумов функции методом градиентного спуска.
* `Practice_2/` — Алгоритмы Дейкстры и А* для поиска кратчайшего пути.
* `Practice_3/` — Реализация алгоритма RRT для поиска пути.
* `Practice_4/` — Метод искусственных потенциальных полей.
* `requirements.txt` — Список зависимостей для Python.
* `.gitignore` — Исключения для системы контроля версий.

## 📝 Описание практических работ

### Практическая работа №1: Метод градиентного спуска
**Задача:** Исследование функции двух переменных и поиск её локальных минимумов методом градиентного спуска.
* Реализован численный расчет частных производных методом конечных разностей.
* Исследовано влияние шага градиентного спуска (с использованием затухания шага) на точность и скорость сходимости.
* Визуализация 3D-поверхности функции и найденной точки минимума с помощью `matplotlib`.

### Практическая работа №2: Алгоритмы Дейкстры и А*
**Задача:** Изучение графового представления пространства и реализация алгоритмов поиска кратчайшего пути.
* **Часть 1:** Поиск кратчайших путей на взвешенном неориентированном графе городов. Сравнение алгоритма Дейкстры и А* (с нулевой эвристикой).
* **Часть 2:** Генерация случайного лабиринта 50x50 и поиск пути из левого верхнего угла в правый нижний. Сравнение алгоритмов по длине пути, количеству посещённых вершин и времени выполнения.

### Практическая работа №4: Метод искусственных потенциальных полей (APF)
**Задача:** Планирование траектории движения мобильного робота в двумерном пространстве с препятствиями.
* Реализован расчет сил притяжения (квадратичный, линейный, гибридный потенциалы) и отталкивания (по формуле Хатиба).
* Реализован выход из локальных минимумов с помощью касательной силы.
* Добавлена поддержка препятствий произвольной формы (круги, прямоугольники, многоугольники).
* **Дополнительные задания:** реализованы нормализация и сглаживание (вариант 2), усиление отталкивания (вариант 3), динамические препятствия (вариант 4).
* **Распределенная система:** реализованы три подхода для группы из 3 роботов: «Цепь», «Гонка за лидером» и «Свободный поиск» (с использованием `tkinter` для панели управления).

## ⚙️ Установка и запуск

### Требования
* **Python 3.10+** (из-за использования современных аннотаций типов, например `float | None`).
* Наличие системного пакета `tkinter` (необходим для работы `matplotlib.use("TkAgg")` и панели управления в Практике №4).

### Инструкция по установке

1. Клонируйте репозиторий и перейдите в папку проекта:
    ```bash
    git clone git@github.com:pavelmino44/UIR_RTS.git
    cd UIR_RTS
    ```

2. Создайте и активируйте виртуальное окружение:
    ```bash
    python -m venv .venv

    # Для Windows:
    .venv\Scripts\activate

    # Для Linux/macOS:
    source .venv/bin/activate
    ```

3. Установите зависимости:
    ```bash
    pip install -r requirements.txt
    ```

4. (Только для Linux) Если при запуске возникает ошибка
`ModuleNotFoundError: No module named 'tkinter'`, установите его через пакетный менеджер ОС:
    ```bash
    sudo apt install python3-tk
    ```

### Запуск
Каждая практическая работа запускается из своей директории. Перейдите в папку нужной практики и запустите `main.py`:
```bash
# Пример для Практики 1
cd Practice_1
python main.py
```
Примечание: Для Практики 4 потребуется закрыть окно симуляции или панель управления `tkinter` для завершения работы программы.
